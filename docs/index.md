# Обзор

Проект курса «Инженерный C++» включает общую библиотеку `Common`, тонкое
консольное приложение `App` для чтения параметров окна и игру, разделённую на
слои `GameCore`, `GamePresentation` и `GameApp`. На проекте отрабатываются
воспроизводимая сборка, тесты, статический анализ, санитайзеры, покрытие кода
и непрерывная интеграция.

Стек проекта: C++23, CMake 3.25+, Conan 2, MSVC (Visual Studio 2022),
Python-скрипты в каталоге `automation/`. Общая конфигурация находится в
библиотеке `Common`; `App` остаётся тонкой точкой входа, а игра использует
отдельные цели для логики, представления и запуска.

## Быстрый старт

Все команды выполняются из корня репозитория (`project/`):

```powershell
python automation/generate_project_files.py
python automation/build_debug.py
.\build\bin\Debug\App.exe
```

`App` читает `config.json` из текущего рабочего каталога. Пример конфигурации
лежит в корне проекта, который используется как рабочий каталог (в том числе
в настройках отладчика Visual Studio).

Конфигурация Release: `python automation/build_release.py`.
Полная очистка сборочных каталогов: `python automation/clean.py`.

## Зависимости

Внешние пакеты задаются в `conanfile.txt` (в том числе `nlohmann_json` и
`GTest`). Профили Conan для Debug и Release лежат в `profiles/`. Подробности
сборочной модели — на странице [Архитектура](architecture.md).
